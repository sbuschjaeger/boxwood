# How-to guides

Short recipes, one task each. They assume you know the basics from the [tutorials](../tutorials/index.md).

- [Use the scikit-learn estimators](estimators.md): CatBoost plus a leaf refit behind `fit` / `predict`.
- [Fit on data larger than memory](large-data.md): memory-mapped arrays, and streams with `update`.
- [Save and load a model](save-load.md): pickle, joblib and the binary format.
- [Use boxwood from C++](cpp.md): link the library, build a `Batch`, predict.
- [Benchmark against CatBoost](benchmark.md): reproduce the speed tables.
